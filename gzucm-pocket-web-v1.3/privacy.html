隐私与安全说明

广中医口袋 Web 是非官方第三方项目，与广州中医药大学无隶属关系。课程成绩和教务会话属个人信息。公开部署前，站点运营者须核实学校访问授权、明确数据处理规则并完成必要的合规评估。

登录信息

本站不要求你填写学校密码。你在学校官方域名使用账号密码或扫码完成认证（含确认步骤）；网站服务器会为当前浏览器单独保留取得的学校会话 Cookie（仅进程内存，最多 12 小时不活动期）。访问令牌通过 Secure、HttpOnly、SameSite=Strict Cookie 保存。服务器重启、休眠或会话退出后，该凭证失效。

一卡通实时查询

本站可在有合法服务器端一卡通会话时读取官方余额和用电明细；目前尚未提供一卡通单独授权回调，因此不能保证网站内自动同步。未获得认证时显示官方页面链接，绝不以演示值冒充实时。学校密码与一卡通 Cookie 不应复制提供给本网站。

课表与成绩

只有经过你授权的教务会话才能请求你的数据。公开模式默认不把学业数据写入浏览器 localStorage，但会展示在当前页面内存中。用户主动下载的 JSON 和日历文件由用户自行保管。云服务运营商可能处理 IP 等必要网络日志；学校系统及云平台隐私政策另行适用。

安全边界

此版本是公开部署测试版，尚未完成真实账号端到端验证、渗透测试或正式学校授权确认。请勿在公共电脑使用，也不要共享含有个人学业数据的导出文件。学校可能限制校外或云服务访问；如遇登录失败请使用官方教务系统。

退出与数据清除

点「设置 → 退出当前学校会话」清空服务器中的本次教务会话。关闭网页不等于退出。公共部署不默认存储你的课表和成绩在浏览器。
